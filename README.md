# Бухгалтерия оплат

Сайт и Android-приложение (APK) для учёта оплат за обучение.

Пользователь **присылает фото/скриншот чека** или **пишет оплату текстом**
(«Сидоров Саша 5000 за октябрь»), а система сама:

1. находит сумму, дату, плательщика, назначение платежа, банк и номер операции;
2. определяет, **за какого ученика или от какого родителя** пришла оплата;
3. фиксирует оплату, а если не уверена — кладёт её в «На проверке» с подсказками.

## Как система узнаёт плательщика

- **ФИО в чеке.** Банки пишут сокращённо: «Иван Петрович С.». Это сопоставляется с
  «Сидоров Иван Петрович».
- **Имя ребёнка в назначении**, в любом падеже и уменьшительной форме:
  «за Сидорова Сашу» → «Сидоров Александр».
- **Родитель с одним ребёнком** → оплата сразу записывается на ребёнка.
  **Родитель с несколькими детьми** → на ребёнка, если он назван («за Машу»), иначе на родителя.
- **Последние цифры телефона** отправителя (переводы по СБП).
- **Сумма**, совпадающая с ежемесячной оплатой ученика.
- **Обучение.** Если вы вручную привязали оплату, система запоминает плательщика,
  и следующий его чек привяжется автоматически.
- **Дубли.** Повторно загруженный тот же чек не создаёт вторую оплату.

Оплата фиксируется автоматически, если уверенность ≥ 85 % и нет похожего второго варианта
(порог задаётся в `AUTO_CONFIRM_SCORE`).

## Возможности

- Экран «Оплата»: камера, галерея или текст, плюс комментарий к фото.
- «Оплаты»: очередь на проверку, привязка в одно касание, фильтр по месяцу, выгрузка в Excel (CSV).
- «Ученики»: ученики, группы, сумма в месяц, родители и их телефоны.
- «Отчёт»: сколько получено за месяц, кто сколько заплатил и кто должен.
- Светлая и тёмная тема, интерфейс под телефон.

## Устройство

```
backend/    FastAPI + SQLite: API, распознавание (Claude API), сопоставление
frontend/   React + Vite: сайт; он же упакован в Android-приложение через Capacitor
  android/  Android-проект (Capacitor)
```

Фото чеков распознаёт Claude (модель `claude-opus-5-5`, через структурированный вывод).
Текстовые сообщения разбираются и без ключа: работает встроенный разборщик суммы и даты.

## Запуск сервера

### Docker (рекомендуется)

```bash
cp .env.example .env      # задайте APP_TOKEN и ANTHROPIC_API_KEY
docker compose up -d --build
```

Сайт откроется на `http://<сервер>:8000`. База и фото хранятся в папке `./data`.
Для доступа из интернета поставьте перед сервером HTTPS (например, Caddy или nginx).

### Без Docker

```bash
cd frontend && npm ci && npm run build && cd ..
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
cd backend && APP_TOKEN=секрет ANTHROPIC_API_KEY=... ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Разработка

```bash
cd backend && ../.venv/bin/uvicorn app.main:app --reload     # API на :8000
cd frontend && npm run dev                                    # сайт на :5173, /api проксируется
cd backend && ../.venv/bin/python -m pytest                   # тесты
```

## Android-приложение (APK)

APK собирается автоматически в GitHub Actions (workflow **Android APK**):

- при каждом пуше APK лежит в артефактах сборки (`buhgalteria-apk`);
- при пуше тега `v*` (например, `v0.1.0`) APK публикуется в **Releases**.

При первом запуске в приложении откройте **Настройки**, укажите адрес сервера
(например, `https://buh.example.ru` или `http://192.168.1.10:8000` в локальной сети) и код доступа.
Чтобы адрес сервера был уже «зашит» в APK, задайте переменную репозитория `API_URL`
(Settings → Secrets and variables → Actions → Variables).

Собрать локально (нужны JDK 21 и Android SDK):

```bash
cd frontend
npm ci && npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

Сейчас собирается debug-APK: его можно установить на телефон напрямую.
Для публикации в Google Play нужно подписать release-сборку своим ключом.

## Настройки сервера

| Переменная | Назначение |
|---|---|
| `APP_TOKEN` | Код доступа к сайту и API. Пусто — вход без кода (только для локальной разработки!) |
| `ANTHROPIC_API_KEY` | Ключ Claude API для распознавания фото |
| `CLAUDE_MODEL` | Модель распознавания, по умолчанию `claude-opus-5-5` |
| `AUTO_CONFIRM_SCORE` | Порог автоматической фиксации, по умолчанию `0.85` |
| `DATA_DIR` | Папка для базы и фото, по умолчанию `./data` |
| `DATABASE_URL` | Строка подключения SQLAlchemy (можно PostgreSQL) |

## API

Документация открывается на `/docs`. Основное:

- `POST /api/payments/recognize`: `file` (фото) и/или `text`. Распознаёт и фиксирует оплату.
- `GET /api/payments?status=needs_review`: оплаты на проверке.
- `PATCH /api/payments/{id}`: `{student_id, parent_id}`, привязать и подтвердить.
- `GET /api/reports/month?month=2026-10`: отчёт за месяц.
- `GET /api/payments/export.csv?month=2026-10`: выгрузка для Excel.
