# Бухгалтерия оплат

Сайт и Android-приложение (APK) для учёта оплат за обучение.

Пользователь **присылает фото/скриншот чека, PDF-квитанцию или выписку** или **пишет оплату
текстом** («Сидоров Саша 5000 за октябрь») в приложении, на сайте или в Telegram-боте,
а система сама:

1. читает чек и находит сумму, дату, плательщика, назначение, банк и номер операции;
2. определяет, **за какого ученика или от какого родителя** пришла оплата;
3. фиксирует оплату, а если не уверена, кладёт её в «На проверке» с подсказками.

**Работает бесплатно, без нейросетей и платных API.** Чек читается прямо на телефоне или в
браузере (Tesseract OCR и PDF.js, файлы распознавания лежат внутри приложения), а затем
разбирается парсером, который знает формат чеков Сбербанка, Т-Банка, ВТБ, Альфа-Банка и
переводов по СБП.

## Как система узнаёт плательщика

- **ФИО в чеке.** Банки пишут сокращённо: «Иван Петрович С.». Это сопоставляется с
  «Сидоров Иван Петрович».
- **Имя ребёнка в назначении**, в любом падеже и уменьшительной форме:
  «за Сидорова Сашу» → «Сидоров Александр».
- **Родитель с одним ребёнком** → оплата сразу записывается на ребёнка.
  **Родитель с несколькими детьми** → на ребёнка, если он назван («за Машу»), иначе на родителя.
- **Последние цифры телефона** отправителя (переводы по СБП).
- **Сумма**, совпадающая с ежемесячной оплатой ученика.
- **Обучение.** Если вы вручную привязали оплату, система запоминает плательщика,
  и следующий его чек привяжется автоматически.
- **Дубли.** Повторно загруженный тот же чек не создаёт вторую оплату.

Оплата фиксируется автоматически, если уверенность ≥ 85 % и нет похожего второго варианта
(порог задаётся в `AUTO_CONFIRM_SCORE`).

## Возможности

- **«Оплата»**: камера, галерея (можно выбрать сразу несколько фото) или PDF, текст —
  по одной оплате в строке, комментарий к фото («за Машу»).
- **Выписки**: со скриншота истории переводов система заберёт все входящие оплаты сразу.
- **«Оплаты»**: очередь на проверку, привязка в одно касание, исправление суммы, даты и
  назначения, просмотр чека, фильтр по месяцу, выгрузка в Excel (CSV).
- **«Ученики»**: ученики, группы, сумма в месяц, родители и их телефоны.
- **«Отчёт»**: сколько получено за месяц, кто сколько заплатил и кто должен;
  нажмите на ученика, чтобы увидеть историю его оплат.
- **Telegram-бот**: перешлите чек боту, он зафиксирует оплату и ответит; если не уверен,
  покажет кнопки «кому относится оплата».
- Светлая и тёмная тема, интерфейс под телефон.

## Устройство

```
backend/    FastAPI + SQLAlchemy (SQLite или Postgres)
  app/receipt_parser.py  разбор текста чеков российских банков
  app/matcher.py         поиск ученика/родителя по ФИО, телефону, сумме
  app/intake.py          приём оплаты из любого канала
  app/ocr.py             чтение чека на сервере (PDF, Tesseract — если установлен)
  app/telegram_bot.py    Telegram-бот (опрос или вебхук)
frontend/   React + Vite: сайт; он же упакован в Android-приложение через Capacitor
  src/ocr.ts             чтение чека на устройстве (Tesseract.js, PDF.js)
  android/               Android-проект (Capacitor)
deploy/     установка на свой сервер одной командой
```

Если задать `ANTHROPIC_API_KEY`, сервер будет дополнительно распознавать чеки нейросетью Claude,
что точнее на плохих фото. Это необязательно.

## Запуск бесплатно на Vercel

1. Зайдите на [vercel.com](https://vercel.com) через GitHub (Sign Up → Continue with GitHub).
2. **Add New… → Project** → выберите репозиторий `buhgalteria` → **Import**.
   Настройки сборки менять не нужно: всё описано в `vercel.json` и `pyproject.toml`.
3. Нажмите **Deploy**. Если Vercel предложит пресет «Services», выберите **FastAPI**
   (или «Import single project» у строки `app`).
4. Подключите бесплатную базу: в проекте **Storage → Create Database → Neon (Postgres)** →
   **Connect**. Затем **Deployments → … → Redeploy**. Без базы данные будут пропадать
   (сайт об этом предупредит).
5. Включите вход через Telegram (см. ниже) и откройте адрес вида `https://buhgalteria-xxx.vercel.app`.

## Вход через Telegram

Один аккаунт на телефоне и компьютере, без паролей:

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя → скопируйте токен.
2. На Vercel: **Settings → Environment Variables** → `TELEGRAM_BOT_TOKEN` = токен → **Save** → **Redeploy**.
3. Откройте сайт → **«Войти через Telegram»** → в боте нажмите **Start** — вход завершится сам.

**Первый вошедший становится владельцем** — войдите сразу после настройки. Если войти попробует
кто-то ещё, владельцу придёт сообщение от бота с кнопкой «Разрешить» (доступом можно управлять и в
«Настройках»). Этот же бот принимает чеки: пришлите ему фото, PDF или текст. Текст и PDF бот читает
сам; фото на Vercel прочитать нечем, поэтому их лучше загружать через приложение (на своём сервере с
Docker бот читает и фото).

Без `TELEGRAM_BOT_TOKEN` и `APP_TOKEN` сайт открыт всем, кто знает адрес.

Ограничения бесплатного тарифа Vercel (Hobby): только некоммерческое использование, файл до 4,5 МБ
(фото приложение само уменьшает, а большой PDF отправит только текстом).

## Запуск на своём сервере

### Одной командой на VPS

Подойдёт любой сервер с Ubuntu 22.04/24.04 (1 ГБ памяти достаточно). Зайдите на него по SSH и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/sl1nGtIG/buhgalteria/main/deploy/install.sh | sudo bash
```

Скрипт поставит Docker, скачает код, спросит домен и токен Telegram-бота (всё можно пропустить),
сам придумает код доступа и запустит сервер. С доменом сайт работает по HTTPS с автоматическим
сертификатом: A-запись домена должна указывать на IP сервера. Повторный запуск той же команды
обновляет программу, данные и настройки сохраняются. Для скачивания скрипта репозиторий должен
быть публичным.

### Docker вручную

```bash
cp .env.example .env      # задайте APP_TOKEN
docker compose up -d --build
```

Сайт откроется на `http://<сервер>:8000`. База и чеки хранятся в папке `./data`.

### Без Docker

```bash
cd frontend && npm ci && npm run build && cd ..
python3 -m venv .venv && .venv/bin/pip install -r backend/requirements.txt
cd backend && APP_TOKEN=секрет ../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Разработка

```bash
cd backend && ../.venv/bin/uvicorn app.main:app --reload     # API на :8000
cd frontend && npm run dev                                    # сайт на :5173, /api проксируется
cd backend && ../.venv/bin/python -m pytest                   # тесты
```

## Android-приложение (APK)

APK собирается в GitHub Actions (workflow **Android APK**), когда меняется приложение:

- на сайте появляется кнопка **«Скачать APK»** («Настройки», а на Android-телефоне — подсказка на
  главной): сборка кладёт файл в `frontend/public/download/` и Vercel публикует его;
- APK также лежит в артефактах сборки (`buhgalteria-apk`), а при пуше тега `v*` — в **Releases**.

Адрес сервера уже «зашит» в APK (`https://buhgalteria-lime.vercel.app`); другой можно задать
переменной репозитория `API_URL` (Settings → Secrets and variables → Actions → Variables) или в
«Настройках» приложения.

Собрать локально (нужны JDK 21 и Android SDK):

```bash
cd frontend
npm ci && npm run build && npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

Сейчас собирается debug-APK: его можно установить на телефон напрямую.
Для публикации в Google Play нужно подписать release-сборку своим ключом.

## Настройки сервера

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather: вход через Telegram и приём чеков ботом |
| `APP_TOKEN` | Необязательно: общий код доступа вместо (или вместе с) входом через Telegram |
| `SESSION_SECRET` | Необязательно: секрет подписи сессий (по умолчанию выводится из токена бота) |
| `DATABASE_URL` | База данных (Postgres). На Vercel подставляется сама при подключении Neon. По умолчанию — SQLite в `DATA_DIR` |
| `TELEGRAM_ALLOWED_CHATS` | Необязательно: ID чатов (например, группы), которым можно присылать чеки боту без входа |
| `TELEGRAM_MODE` | `polling` (свой сервер, по умолчанию) или `webhook` (по умолчанию на Vercel) |
| `AUTO_CONFIRM_SCORE` | Порог автоматической фиксации, по умолчанию `0.85` |
| `MAX_UPLOAD_MB` | Максимальный размер файла чека (на Vercel — 4) |
| `ANTHROPIC_API_KEY` | Необязательно: распознавание чеков нейросетью Claude на сервере |
| `DATA_DIR` | Папка для SQLite-базы, по умолчанию `./data` |

## API

Документация открывается на `/docs`. Основное:

- `POST /api/payments/recognize`: `file` (фото или PDF), `ocr_text` (текст чека, прочитанный на
  устройстве) и/или `text`. Распознаёт и фиксирует оплаты, возвращает `items`: по одной записи на
  каждую найденную оплату.
- `GET /api/payments?status=needs_review`: оплаты на проверке.
- `PATCH /api/payments/{id}`: `{student_id, parent_id}`, привязать и подтвердить.
- `GET /api/reports/month?month=2026-10`: отчёт за месяц.
- `GET /api/payments/export.csv?month=2026-10`: выгрузка для Excel.
